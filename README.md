# SkiTracker Firmware (ESP32 + MPU-6050)

Прошивка для двух независимых беспроводных датчиков горных лыж (левая и правая лыжа) на базе **ESP32-S3** и **ESP32-CAM** с IMU-сенсорами **MPU-6050**.

Обе платы работают как независимые **BLE-серверы (NimBLE)**, опрашивают датчики на частоте **200 Гц** и отправляют бинарные пакеты с углами по трём осям (`X`, `Y`, `Z`) на частоте **25 Гц** в Android-приложение **SkiTrackerApp**.

---

## Архитектура проекта

Один общий исходный код обслуживает обе платы. Сторона лыжи (`L` / `R`), распиновка I2C и BLE-имя выбираются автоматически через профили в `platformio.ini`.

```text
SkiTracker-ESP32/
├── platformio.ini          # Профили сборки: ski_left_s3 (L) и ski_right_cam (R)
├── include/
│   ├── config.h            # Авто-выбор пинов и BLE-имени по флагу сборки, UUID
│   └── types.h             # 16-байтный бинарный пакет телеметрии и коды команд
└── src/
    ├── main.cpp            # Главный цикл: команды, опрос IMU (200 Гц), BLE (25 Гц)
    ├── imu_sensor.h/.cpp   # Инициализация MPU-6050 (0x68/0x69), калибровка, фильтрация
    └── ble_service.h/.cpp  # NimBLE-сервер, Notify телеметрии, приём команд
```

## Железо и схемы подключения

На каждой плате установлен один датчик **MPU-6050**. Пин `AD0` остаётся неподключённым (адрес `0x68`), при этом прошивка автоматически проверяет оба адреса (`0x68` и `0x69`).

### Левая лыжа (`SkiTracker_L`) — ESP32-S3-N16R8

| Пин MPU-6050 | Пин ESP32-S3 |
| ------------ | ------------ |
| **VCC**      | `3.3V`       |
| **GND**      | `GND`        |
| **SDA**      | `GPIO 8`     |
| **SCL**      | `GPIO 9`     |

### Правая лыжа (`SkiTracker_R`) — ESP32-CAM (без камеры и SD)

| Пин MPU-6050 | Пин ESP32-CAM |
| ------------ | ------------- |
| **VCC**      | `3.3V`        |
| **GND**      | `GND`         |
| **SDA**      | `GPIO 14`     |
| **SCL**      | `GPIO 15`     |

## Переключение между левой и правой лыжей

Править код для смены лыжи **не нужно**. В `platformio.ini` настроены два окружения:

| Профиль PlatformIO  | Плата                | Имя в BLE      | Пины I2C (SDA / SCL)  |
| ------------------- | -------------------- | -------------- | --------------------- |
| `env:ski_left_s3`   | `esp32-s3-devkitc-1` | `SkiTracker_L` | `GPIO 8` / `GPIO 9`   |
| `env:ski_right_cam` | `esp32cam`           | `SkiTracker_R` | `GPIO 14` / `GPIO 15` |

### Как переключить в VS Code (PlatformIO)

1. В нижней синей панели статуса VS Code нажмите на текущее окружение (например, `Default (Ski_App)` или `env:ski_left_s3`).
2. В выпадающем списке выберите **`env:ski_left_s3`** (левая) или **`env:ski_right_cam`** (правая).
3. Нажмите **Upload** (стрелка `→` на нижней панели).

### Как переключить через терминал (CLI)

```bash
# Прошить левую лыжу (ESP32-S3)
pio run -e ski_left_s3 -t upload

# Прошить правую лыжу (ESP32-CAM)
pio run -e ski_right_cam -t upload

# Открыть Serial Monitor (115200 бод)
pio device monitor -b 115200
```

> **Нужно использовать две одинаковые платы ESP32-S3?**  
> Просто скопируйте секцию `[env:ski_left_s3]` в `platformio.ini` с именем `[env:ski_right_s3]`, поменяйте флаг на `-D SKI_SIDE_RIGHT` и при необходимости скорректируйте `I2C_SDA_PIN` / `I2C_SCL_PIN` в `include/config.h`.

## Как прошить ESP32-CAM через USB-UART (FTDI FT232RL)

Если нет переходника `ESP32-CAM-MB`, прошивка выполняется через обычный адаптер **FTDI FT232RL**:

1. **Перемычка напряжения на FTDI:** установите в положение **`5V`** (встроенный стабилизатор 3.3V на FTDI слишком слабый для запуска ESP32-CAM).
2. **Подключение проводов:**
   - `FTDI VCC (5V)` → `ESP32-CAM 5V`
   - `FTDI GND` → `ESP32-CAM GND` _(строго пин GND рядом с `5V`, а не возле `U0R`)_
   - `FTDI TX` → `ESP32-CAM U0R`
   - `FTDI RX` → `ESP32-CAM U0T`
3. **Режим загрузки:** установите перемычку **`IO0` ↔ `GND`** на самой ESP32-CAM.
4. Запустите **Upload** в профиле `env:ski_right_cam`. Когда в терминале появится `Connecting........_____`, коротко нажмите кнопку **RST** на ESP32-CAM.
5. После завершения прошивки **снимите перемычку `IO0` ↔ `GND`** и снова нажмите **RST** для обычного запуска.

## Требования и развёртывание проекта

1. Установите **VS Code** и расширение **PlatformIO IDE**.
2. Клонируйте репозиторий и откройте папку в VS Code:
   ```bash
   git clone [https://github.com/](https://github.com/)<ваш_ник>/SkiTracker-ESP32.git
   ```
3. PlatformIO автоматически скачает платформу `espressif32` и все зависимости из `platformio.ini`:
   - `adafruit/Adafruit MPU6050 @ ^2.2.6`
   - `adafruit/Adafruit Unified Sensor @ ^1.1.14`
   - `h2zero/NimBLE-Arduino @ ^1.4.2`
4. Выберите нужный профиль (`ski_left_s3` или `ski_right_cam`) и выполните **Upload**.

При успешном запуске в Serial Monitor (`115200`) появится:

```text
Запуск узла: SkiTracker_L
[IMU] MPU-6050 готов и откалиброван.
[BLE] Запущен как: SkiTracker_L
```

## BLE-протокол

| Параметр                                     | Значение                               |
| -------------------------------------------- | -------------------------------------- |
| Service UUID                                 | `4fafc201-1fb5-459e-8fcc-c5c9c331914b` |
| Telemetry Characteristic (`READ`, `NOTIFY`)  | `beb5483e-36e1-4688-b7f5-ea07361b26a8` |
| Command Characteristic (`WRITE`, `WRITE_NR`) | `6e400002-b5a3-f393-e0a9-e50e24dcca9e` |

### Бинарный пакет телеметрии (16 байт, little-endian)

```cpp
struct __attribute__((packed)) SkiTelemetryPacket {
  uint32_t timestampMs; // 0..3   Время с запуска (мс)
  float angleX;         // 4..7   Угол по оси X (градусы)
  float angleY;         // 8..11  Угол по оси Y (градусы)
  float angleZ;         // 12..15 Угол по оси Z (градусы)
};
```

### Команды от приложения (1 байт)

- `0x01` — сброс текущего нуля (`resetZero`)
- `0x02` — полная перекалибровка гироскопа и акселерометра (`calibrate`, датчики должны быть неподвижны)
